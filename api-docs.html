مستندات API حق فراموش شدن

اطلاعات حذف حساب سرویس‌ها را به برنامه، وب‌سایت یا افزونهٔ خود اضافه کنید. API عمومی با درخواست GET و بدون کلید قابل‌استفاده است.

شروع سریع فیلتر و صفحه‌بندی ساختار پاسخ آزمایش API

شروع سریع

وضعیت خروجی و مقدارهای معتبر فیلترها را از مسیر بررسی سلامت بخوانید. پاسخ status: "ok" یعنی خروجی داده‌ها ساخته شده است.

# بررسی سلامت خروجی
curl -fSsL 'https://rtbf.ir/api/v1/'

# همهٔ سرویس‌ها، از جدیدترین به قدیمی‌ترین
curl -fSsL 'https://rtbf.ir/api/v1/services/'

# اطلاعات یک سرویس با دامنهٔ ثبت‌شده
curl -fSsL 'https://rtbf.ir/api/v1/services/aparat.com'

مسیر تک‌سرویس، دامنهٔ دقیق ثبت‌شده را می‌گیرد. برای مثال، از URL کامل آپارات، فقط aparat.com را در مسیر بگذارید. دامنهٔ ثبت‌نشده HTTP 404 می‌دهد.

فیلترها و صفحه‌بندی

چهار فیلتر را دقیقاً با ترتیب category، priority، status و sort در مسیر بنویسید. برای برداشتن محدودیت دسته‌بندی، اولویت یا وضعیت از all استفاده کنید.

curl -fSsL 'https://rtbf.ir/api/v1/services/category=e-commerce&priority=2&status=medium-label&sort=oldest'

curl -fSsL 'https://rtbf.ir/api/v1/services/category=all&priority=all&status=all&sort=newest'

این مقدارها بخشی از مسیرند. ? اضافه نکنید و ترتیب یا نام فیلترها را تغییر ندهید. در ترمینال، آدرس را داخل کوتیشن بگذارید تا & درست ارسال شود.

مقدارهای فیلترها
فیلترمقدار
categoryall یا یکی از مقدارهای filters.category در پاسخ بررسی سلامت. دستهٔ خالی با uncategorized مشخص می‌شود.
priorityall، 1، 2 یا 3
statusall، easy-label، medium-label، hard-label یا impossible-label
sortnewest یا oldest. رکوردهای انتهای فایل منبع جدیدترند.

مسیر /services/ همهٔ سرویس‌ها را می‌دهد. پاسخ فیلترشده حداکثر ۲۰ سرویس در هر صفحه دارد. برای صفحهٔ بعد و قبل، آدرس‌های links.next و links.previous را دنبال کنید. از صفحهٔ دوم، شمارهٔ صفحه به انتهای مسیر اضافه می‌شود. مسیر صفحهٔ اول شماره ندارد.

curl -fSsL 'https://rtbf.ir/api/v1/services/category=all&priority=all&status=all&sort=newest&page=2'

ترکیب معتبر بدون نتیجه، data: [] و meta.total: 0 می‌دهد. فیلتر نامعتبر، ترتیب متفاوت پارامترها و صفحهٔ خارج از محدوده HTTP 404 می‌دهند.

ساختار پاسخ

پاسخ‌ها api_version و revision دارند. اثر انگشت revision با تغییر فایل منبع عوض می‌شود. data در تک‌سرویس یک شیء و در فهرست یک آرایه است. meta.total تعداد کل نتایج را نشان می‌دهد.

فیلدهای هر سرویس
فیلدتوضیح
domain، nameدامنهٔ ثبت‌شده و نام سرویس
website_urlآدرس کامل وب‌سایت
delete_urlآدرس کامل حذف حساب یا null در نبود لینک مستقیم
info، referencesراهنمای حذف به‌صورت متن ساده و آرایهٔ پیوندهای مرجع
difficulty، statusشرح فارسی سختی حذف و کد آن با پسوند -label
priority، categoryاولویت عددی و دسته‌بندی سرویس

خروجی با UTF-8 و بدنهٔ JSON است. برای خواندن از JavaScript می‌توانید از fetch(url).then(response => response.json()) استفاده کنید؛ پیش از آن response.ok را بررسی کنید، چون پاسخ خطای میزبان ممکن است HTML باشد. راهنمای سرویس را با textContent نمایش دهید.

GitHub Pages برای مسیرهای دایرکتوری /api/v1/ و /services/ هدر text/html می‌فرستد، هرچند بدنه JSON است. اگر برنامهٔ شما هدر application/json می‌خواهد، از /api/v1/index.json و /api/v1/services/index.json استفاده کنید. مسیر تک‌سرویس و فیلترها هم نسخهٔ معادل با پسوند .json دارند.

API فقط خواندنی است. برای اصلاح داده‌ها از ثبت گزارش استفاده کنید. فایل data/data.json با ساختار قبلی برای افزونه‌ها در دسترس است.

انتشار و استفاده

با هر پوش به شاخهٔ اصلی، GitHub Actions خروجی‌ها را از data/data.json می‌سازد، تغییرات تولیدی را خودکار کامیت و پوش می‌کند و سپس سایت را منتشر می‌کند. افزودن، ویرایش یا حذف سرویس فقط در فایل منبع انجام می‌شود. خروجی‌ها هنگام انتشار به‌روز می‌شوند؛ کش مرورگر و CDN ممکن است دریافت تغییرات را به تأخیر بیندازد.

محتوا با مشارکت کاربران تهیه می‌شود. پیش از اقدام به حذف حساب، راهنمای رسمی سرویس را هم بررسی کنید. هنگام بازنشر، منبع rtbf.ir و مجوز Apache-2.0 را ذکر کنید.

این سرویس چگونه کار می‌کند؟

بسیاری از سرویس‌های اینترنتی این‌گونه عمل می‌کنند که امکان حذف حساب‌کاربری را به شما نمی‌دهند و از نظر ما کاربران این موضوع نقض حریم شخصی است. با توجه به حق فراموش شدن یا Right to be forgotten این یک تضاد می‌باشد.

ایده‌ی اولیه‌ی این سرویس از justdeleteme گرفته شده است و بعد از این توییت تصمیم به راه‌اندازی آن گرفتم.

اگر قصد مشارکت دارید از گیت هاب این کار را انجام دهید.
