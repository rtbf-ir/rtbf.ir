مستندات API حق فراموش شدن

اطلاعات حذف حساب سرویس‌ها را به برنامه، وب‌سایت یا افزونهٔ خود اضافه کنید. API عمومی با درخواست GET و بدون کلید قابل‌استفاده است.

شروع سریع فیلتر و صفحه‌بندی ساختار پاسخ جست‌وجوی URL آزمایش API

شروع سریع

فهرست امکانات و مقدارهای معتبر را از index.json بگیرید. برای اطلاعات یک سرویس، دامنه را در مسیر زیر قرار دهید.

curl https://rtbf.ir/api/v1/services/aparat.com.json

دریافت همهٔ سرویس‌ها و صفحهٔ اول دایرکتوری هم در دسترس‌اند. خروجی JSON با UTF-8 است.

فیلترها و صفحه‌بندی

برای فیلتر کردن، مقدارها را به ترتیب در مسیر قرار دهید. مقدار all همهٔ موارد را انتخاب می‌کند. هر صفحه حداکثر ۲۰ سرویس دارد.

GET /api/v1/directory/{category}/{status}/{priority}/{sort}/{page}.json

# سرویس‌دهنده‌های زیرساخت با حذف سخت، همهٔ اولویت‌ها، جدیدترین، صفحهٔ اول
GET /api/v1/directory/provider/hard/all/newest/1.json
پارامترهای مسیر دایرکتوری
پارامترمقدار
categoryall یا یکی از مقدارهای filters.category در فهرست امکانات. دستهٔ خالی با uncategorized مشخص می‌شود.
statusall، easy (ساده)، medium (متوسط)، hard (سخت)، impossible (غیرممکن)
priorityall، 1، 2 یا 3
sortnewest یا oldest. ترتیب از جای رکورد در فایل داده می‌آید. رکوردهای انتهای فایل جدیدترند.
pageعدد صحیح از 1 تا meta.total_pages

با دنبال کردن links.next یا links.previous صفحه را عوض کنید. این مسیرها از ریشهٔ همان میزبان هستند. نبودن صفحهٔ بعد یا قبل با null مشخص می‌شود.

const response = await fetch("https://rtbf.ir/api/v1/directory/all/all/all/newest/1.json");
if (!response.ok) throw new Error("HTTP " + response.status);
const result = await response.json();
if (result.links.next) {
  const nextURL = new URL(result.links.next, "https://rtbf.ir");
  const nextPage = await fetch(nextURL).then(response => response.json());
}

این مسیرها فایل‌های JSON آماده روی GitHub Pages هستند. فیلترها در خود مسیر تعریف می‌شوند. تغییر پارامترهایی مثل ?page=2 یا ?url=... پاسخ فایل را تغییر نمی‌دهد. جست‌وجوی متنی و پردازش URL کامل از طریق کلاینت JavaScript پایین صفحه انجام می‌شود.

ساختار پاسخ و خطاها

همهٔ پاسخ‌ها api_version و revision دارند. revision اثر انگشت دادهٔ منبع است و با تغییر داده‌ها عوض می‌شود. پاسخ یک سرویس، همان رکورد را در data برمی‌گرداند.

فیلدهای هر سرویس در نسخهٔ ۱
فیلدتوضیح
domainدامنهٔ یکتای سرویس بدون پروتکل و مسیر
nameنام نمایشی سرویس
website_urlآدرس کامل وب‌سایت
delete_urlآدرس کامل حذف حساب یا null. مقدار خالی به معنی نبود لینک مستقیم ثبت‌شده است.
infoراهنمای حذف به صورت متن ساده. برای نمایش در صفحه از textContent استفاده کنید.
referencesپیوندهای HTTP(S) موجود در راهنمای منبع یا آرایهٔ خالی

priority، categoryاولویت عددی و دسته‌بندی سرویس
  • ترکیب معتبر بدون نتیجه، صفحهٔ اول با data: [] و meta.total: 0 دارد.
  • دامنهٔ ثبت‌نشده، مقدار فیلتر نامعتبر و شمارهٔ صفحهٔ خارج از محدوده، HTTP 404 برمی‌گردانند. پاسخ خطای GitHub Pages ممکن است HTML باشد. پیش از خواندن JSON، response.ok را بررسی کنید.
  • مسیر اصلی data/data.json با قالب قبلی برای افزونه‌ها در دسترس است.
  • API فقط خواندنی است. برای اصلاح اطلاعات از ثبت گزارش استفاده کنید.

دریافت URL و جست‌وجوی متنی با JavaScript

کلاینت client.js را به صورت ES module وارد کنید. URL یا دامنه را به lookup بدهید. مسیر و پارامترهای URL کنار گذاشته می‌شوند و دقیق‌ترین دامنهٔ ثبت‌شده تطبیق داده می‌شود. زیر‌دامنه‌ها هم با دامنهٔ سرویس تطبیق داده می‌شوند. آدرس ورودی برای پردازش به سرور ارسال نمی‌شود.

import { createClient } from "https://rtbf.ir/api/v1/client.js";
const api = createClient();

const service = await api.lookup("https://www.aparat.com/example?ref=my-app");
// service.data برای سرویس ثبت‌نشده null است.

const page = await api.list({
  q: "ابر", category: "provider", status: "all", priority: "all",
  sort: "newest", page: 1, pageSize: 20
});

کلاینت در اولین درخواست، همهٔ داده‌ها را دریافت و تا عمر همان نمونه در حافظه نگه می‌دارد. جست‌وجو و صفحه‌بندی بعدی محلی انجام می‌شود. جست‌وجو متنی است و تفاوت «ی/ي»، «ک/ك»، فاصله‌های اضافه و بزرگی حروف انگلیسی را نادیده می‌گیرد. pageSize از ۱ تا ۱۰۰ است و مقدار پیش‌فرض ۲۰ دارد. برای تازه کردن داده‌ها یک نمونهٔ جدید از کلاینت بسازید.

ورودی URL نامعتبر یا فیلتر نامعتبر خطا می‌دهد. در کلاینت، صفحهٔ خارج از محدوده RangeError و شکست درخواست RtbfApiError با فیلد status برمی‌گرداند.

انتشار و استفاده

منبع داده‌ها فایل data/data.json است. خروجی‌های API هنگام انتشار به‌صورت خودکار از همین فایل ساخته می‌شوند. افزودن، ویرایش یا حذف سرویس فقط در فایل منبع انجام می‌شود. داده‌ها با انتشار نسخهٔ جدید سایت به‌روز می‌شوند. کش مرورگر و CDN ممکن است دریافت تغییرات را به تأخیر بیندازد. دسترسی مرورگر از دامنه‌های دیگر تابع هدر CORS میزبان است. تنظیم فعلی فایل‌های دادهٔ rtbf.ir اجازهٔ خواندن عمومی می‌دهد.

محتوا با مشارکت کاربران تهیه می‌شود. پیش از اقدام به حذف حساب، راهنمای رسمی سرویس را هم بررسی کنید. هنگام بازنشر، منبع rtbf.ir و مجوز Apache-2.0 را ذکر کنید.

این سرویس چگونه کار می‌کند؟

بسیاری از سرویس‌های اینترنتی این‌گونه عمل می‌کنند که امکان حذف حساب‌کاربری را به شما نمی‌دهند و از نظر ما کاربران این موضوع نقض حریم شخصی است. با توجه به حق فراموش شدن یا Right to be forgotten این یک تضاد می‌باشد.

ایده‌ی اولیه‌ی این سرویس از justdeleteme گرفته شده است و بعد از این توییت تصمیم به راه‌اندازی آن گرفتم.

اگر قصد مشارکت دارید از گیت هاب این کار را انجام دهید.
